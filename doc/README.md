This is the documentation and sample configuration files for ImageShare.

- **[Install Guide](INSTALL.md)** - How to run ImageShare on your own computer, NAS, or home server. It includes instructions for Docker Compose, Apple Container, Docker Desktop, and other methods.
- **[Production Server Guide](PROD.md)** - How to run ImageShare on a public web server, with a reverse proxy for optional HTTPS support.
- **[List of Settings](SETTINGS.md)** - The full list of options for ImageShare, including how to enable Plausible Analytics support and uploading to Imgur.

The [sample Docker Compose file](docker-compose.yaml) is also available if you already know what you're doing!
